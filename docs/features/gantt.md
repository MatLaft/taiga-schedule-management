# Gantt chart

The Gantt chart displays epics, user stories, and tasks in a temporal tree.

Implemented capabilities:

- moving and resizing bars;
- creating dates directly from the chart;
- hierarchical reordering;
- multiple time scales and zoom controls;
- current-day indicator;
- activity colors;
- explicit lock and editing states;
- undo/redo support for applicable operations.
