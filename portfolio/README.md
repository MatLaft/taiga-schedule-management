# Portfolio assets

This directory currently contains only the structure and guidance for future
visual assets. Add the files once a publication-ready version is available.

## Expected files

```text
portfolio/
├── demo.gif
├── screenshots/
│   ├── schedule-list.png
│   ├── gantt.png
│   ├── dependencies.png
│   ├── critical-path.png
│   └── permissions.png
└── diagrams/
    └── architecture.svg
```

After adding `demo.gif`, replace the explanatory comment near the top of the
main README with the corresponding Markdown image.

Before publishing, verify that screenshots do not expose names, email
addresses, tokens, internal URLs, or personal data.
