# Changelog

Notable changes to the portfolio and orchestration repository are documented
here. Component-level implementation changes remain in the changelogs and Git
histories of the corresponding submodules.

- Moved Docker infrastructure under `infrastructure/`.

- Added project, architecture, feature, testing, and media documentation.
- Replaced the tracked local environment file with a safe example.
